個人介紹網站｜使用說明

檔案內容
- index.html：完整的個人介紹網站（HTML、CSS、JavaScript 都已包含在同一個檔案中）

如何預覽
1. 將 index.html 下載到電腦。
2. 直接雙擊 index.html，使用 Chrome、Edge 或其他瀏覽器開啟。

如何修改
- 用 VS Code、記事本或其他文字編輯器開啟 index.html。
- 搜尋「王永怡」可修改姓名與相關介紹。
- 搜尋「your.email@example.com」並換成你的電子郵件。
- 經歷與興趣文字都可以直接編輯。

如何上傳到網站
- GitHub Pages：建立 GitHub repository，將 index.html 上傳至 repository 根目錄，再到 Settings → Pages 啟用部署。
- Netlify：登入 Netlify，將包含 index.html 的資料夾拖曳至手動部署區。
- 自己的主機／學校網站：將 index.html 上傳到網站根目錄或指定資料夾。

注意
這是靜態網站，不需要安裝套件或執行建置流程。上線前請檢查個人資訊、電子郵件與經歷內容是否正確。
